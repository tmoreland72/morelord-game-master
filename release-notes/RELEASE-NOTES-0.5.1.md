# Morelord game-master 0.5.1

## What Changed

### Improvements

- Shared Core Mass Combat cycles attacks across living targets before repeating; misses advance the cycle, dead targets are skipped, and excess killing-blow damage is lost.
- Removed tray styles that affected other Morelord dialogs so shared controls, stacks, and footers use Core layout. Native activity/save dialog behavior was verified through Encounters in Dev1.

- Requires Morelord Core 0.9.4 or later. Update Core first, then refresh connected clients.

## Compatibility

- Verified on Foundry VTT 14.370 with D&D5e 6.1.1 in Dev1.
